- iced window

- terminal backend interface
- hard-coded connection proof
- PTY resize proof

- export TOML/JSON backup

## P3: Terminal Polish

- scrollback
- search
- themes
- keyboard shortcuts
- mouse selection
- bracketed paste
- Unicode width compatibility
